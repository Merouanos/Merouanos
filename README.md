## 🌍 ClimateCraft

> Built for ReduceCO2Now to make climate change something players can experience rather than just read about.

In a normal Minecraft world, you can cut forests and burn coal without thinking about the consequences.

**ClimateCraft changes that.**

Every player action affects an atmospheric CO2 system. As CO2 rises, the environment changes around the player.

### What I built

```text
Dual CO2 simulation           -> atmospheric pressure model
Threshold-based effects       -> desertification and ecosystem changes
Sea level and wildfire logic  -> driven by CO2 thresholds
Real-time HUD                 -> live CO2 and temperature information
Hunter character              -> original gameplay system I designed and built
Release pipeline              -> empty TypeScript repo to public release
```

I built the first playable version in **two weeks**, worked directly with the founder on product and game design, and owned the implementation through release.

**Result: 100+ organic downloads with no paid marketing.**

## 📡 IoT Monitoring Dashboard

> A full-stack monitoring platform connecting physical sensors to a web application.

I wanted to build something where the data was real, so I connected an Arduino with a DHT sensor to a Node.js backend and React dashboard.

```text
Arduino + DHT sensor    -> live temperature and humidity data
Node.js REST API        -> receives and serves sensor data
React + TypeScript      -> real-time dashboard and historical charts
SQLite                  -> persistent data storage
Alert system            -> warning and critical thresholds
Authentication          -> protected user access
Simulation mode         -> full system without physical hardware
```

This gave me hands-on experience across the full path from hardware and data collection to APIs, storage and user-facing software.
