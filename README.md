## About me

I'm a Product Engineer based in Algeria, currently working remotely as a Product Engineer intern at **ReduceCO2Now**, a German environmental organization.

I enjoy taking ideas from an empty repository to a real product — designing the system, building the UI and backend, solving problems along the way, and shipping something people actually use. I pay attention to the details most engineers skip past, and I'd rather ship something small and finished than something large and half-working.

## What I've built

### 🌍 ClimateCraft TypeScript · Minecraft Bedrock Scripting API
> A climate-simulation Minecraft Bedrock mod built for ReduceCO2Now, a German environmental organization. Every player action feeds into an atmospheric CO2 pool — cross certain thresholds and your world starts changing around you.

- Built the first playable version in two weeks from an empty repository
- Designed and implemented the dual CO2 pool simulation, desertification mechanics, ecosystem collapse, sea level rise, and a real-time in-game HUD
- Collaborated directly with the founder on product direction and game design
- Contributed original ideas including the design of the Hunter character
- Released publicly on CurseForge — **100+ organic downloads with zero marketing**

**[View on CurseForge →](https://www.curseforge.com/minecraft-bedrock/addons/climatecraft)**

---

### 📡 IoT Monitoring Dashboard React · TypeScript · Node.js · SQLite · Arduino
> An end-to-end IoT monitoring system connecting real Arduino hardware to a full-stack web application.

- Arduino DHT sensors feed real-time data into a Node.js REST API
- React/TypeScript dashboard displays live readings with threshold-based alerts
- SQLite stores historical data visualized through interactive Recharts graphs
- User authentication system
- Simulation mode for full demo without physical hardware attached

**[View on GitHub →](https://github.com/Merouanos/arduino-IoT)**
