# 🚀 Things I've actually built

## 🌍 ClimateCraft

**TypeScript · Minecraft Bedrock Scripting API**

> A climate-simulation Minecraft Bedrock mod built for ReduceCO2Now.  
> Every player action affects an atmospheric CO₂ system, and crossing thresholds changes the world around the player.

### What I did

- Built the **first playable version in two weeks** from an empty repository
- Designed and implemented the **dual CO₂ pool simulation**
- Built desertification, ecosystem collapse and sea-level-rise mechanics
- Created a **real-time in-game HUD**
- Worked directly with the founder on product direction and game design
- Contributed original gameplay ideas including the **Hunter** character
- Owned implementation, iteration and release

### Result

**Publicly released on CurseForge · 100+ organic downloads · 0 paid marketing**
